# Topview MCP in Claude Guide: Grow With Khalaf

An Arabic guide to adding [Topview MCP](https://www.topview.ai/mcp) to Claude as a custom connector (`https://mcp.topview.ai/claude`), connecting a Topview account, and sending one message that asks for a full campaign: Audience Insight, Message Map, Campaign Plan, Content Brief, then image and video ads. It includes a fix for the "URL must start with https://" error and a copyable campaign prompt for B2B companies.

Live page: https://mohamedkhalafalla.github.io/gwk-topview-guide/
